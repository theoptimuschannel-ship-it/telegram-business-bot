# Telegram Business бот: бэкап удалённых/изменённых сообщений и «!»-команды

Бот подключается к вашему личному аккаунту через Telegram Business и:

- сохраняет все сообщения в SQLite и присылает вам в бота то, что собеседник **удалил** или **изменил** (с переотправкой медиа);
- выполняет команды, которые вы пишете в любом личном чате с префиксом `!` (`!сердечки`, `!печатает`, `!help`);
- автоматически чистит записи старше N дней.

Стек: Python 3.9+, aiogram 3.22+, aiosqlite.

## Установка

### 1. Создать бота
1. В [@BotFather](https://t.me/BotFather) → `/newbot`, получите токен.
2. `/mybots` → ваш бот → **Bot Settings → Business Mode** → включить.
3. Свой числовой ID узнайте у [@userinfobot](https://t.me/userinfobot).

### 2. Заполнить `.env`
```bash
cp .env.example .env
```
Укажите `BOT_TOKEN` и `OWNER_ID`. По желанию: `RETENTION_DAYS` (по умолчанию 30), `TIMEZONE` (например `Europe/Moscow`), `ANIM_DELAY`.

### 3. Запустить
```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python bot.py
```
Затем откройте бота и нажмите `/start` — без этого он не сможет писать вам в личку.

**Docker (сервер 24/7):**
```bash
docker build -t business-bot .
docker run -d --name business-bot --restart unless-stopped \
  --env-file .env -v $(pwd)/data:/app/data business-bot
docker logs -f business-bot
```
БД и логи лежат в `data/` (том), поэтому переживают перезапуск контейнера.

### 4. Подключить бота в Telegram
**Настройки → Telegram для бизнеса → Чат-боты** → введите username бота и выдайте права:
- **читать сообщения** — обязательно, иначе бэкап не работает;
- **отвечать на сообщения** — нужно для анимаций (отправка от вашего имени);
- **удалять отправленные сообщения** — нужно для запасного пути анимаций и чтобы убирать `!help` из чата.

После подключения бот напишет вам, какие права выданы. Подключения аккаунтов, которых нет в списке доступа, игнорируются (см. «Несколько пользователей»).

## Несколько пользователей
Один бот может обслуживать нескольких людей. У каждого свои сообщения, заметки, напоминания, настройки и автоответы, чужих данных он не видит.

Как добавить человека (делает администратор — тот, чей ID в `OWNER_ID`):
1. `/adduser 123456789` — ID человека (узнать можно у @userinfobot).
2. Человек открывает бота, нажимает `/start` и **принимает условия** (там прямо сказано, что бот хранит сообщения на сервере администратора и тот технически может получить к ним доступ).
3. Человек подключает бота в «Чат-боты». Дальше всё работает так же, как у вас.

Остальное:
- `/users` — список (id, имя, число сообщений; содержимое сообщений администратору не показывается).
- `/removeuser id` — убрать человека и **удалить все его данные**.
- `/deletedata` — любой пользователь может сам стереть все свои данные.
- Без добавления и согласия бот игнорирует чужие подключения, а в личке на `/start` отвечает «Доступ закрыт» и показывает ID.
- Существующая база при первом запуске новой версии мигрирует автоматически: все старые данные достаются администратору.

> Честно предупредите людей: администратор хостит бота и технически видит базу. Подключайте только тех, кто осознанно на это согласен.

## Команды в личной переписке с ботом
| Команда | Что делает |
|---|---|
| `/start` | статус подключения и права |
| `/settings` | уведомления об удалениях, изменениях, о своих сообщениях |
| `/stats` | сколько сообщений сохранено, удалений и изменений поймано |
| `/chat имя\|@username\|id` | последние 20 сообщений чата из бэкапа |
| `/search слово` | поиск по всему бэкапу (регистр не важен, в том числе кириллица) |
| `/export [имя]` | выгрузка бэкапа в JSON-файл |
| `/mute [имя]` | не уведомлять об удалениях/правках в этом чате; повтор — вернуть; без аргумента — список |
| `/deletedata` | удалить все мои данные |
| `/ghost` | режим «только удаления» (повтор — выключить) |
| `/away on\|off` · `/away text …` · `/away hours 23:00-08:00` | автоответчик: раз в 6 часов на чат, в заданные часы (`hours off` — всегда) |
| `/reply add слово = ответ` · `/reply list` · `/reply del N` | автоответы по ключевым словам |

## Команды с `!` в любом чате
Команды, помеченные «в чат», подставляют результат вместо вашей команды. «В бота» — ответ приходит только вам, а сама команда убирается из чата.

**Анимации** (`!стоп` прерывает любую; в финале можно добавить текст)
| Команда | |
|---|---|
| `!сердечки` / `!hearts` | сердце из разноцветных сердечек |
| `!печатает [текст]` | «печатает...» или эффект печатной машинки |
| `!ракета` · `!луна` · `!часы` | ракета и салют · фазы луны · крутящиеся часы |
| `!дождь` · `!снег` | падающие капли / снежинки |
| `!загрузка [текст]` | полоса прогресса |
| `!взлом [цель]` | шуточный «взлом» |
| `!таймер 5м` | обратный отсчёт в чате (4 с … 1 ч) |
| `!стоп` / `!stop` | остановить анимацию в этом чате |

**Текст** (в чат; текст берётся после команды или из сообщения, на которое вы ответили)
| Команда | |
|---|---|
| `!жирный` `!курсив` `!код` `!спойлер` | форматирование |
| `!переверни` | вверх ногами (латиница) |
| `!транслит` | кириллица → латиница |
| `!раскладка` | исправить набранное не в той раскладке |
| `!шрифт текст` | в бота: примеры всех стилей; `!шрифт script текст` — в чат (bold, bolditalic, script, gothic, sans, mono, circle, wide) |

**Полезное**
| Команда | |
|---|---|
| `!курс [usd eur btc ton …]` | курс ЦБ РФ и крипты (в чат) |
| `!погода город` | погода (в чат) |
| `!перевод [en\|ru\|de…] текст` | перевод, можно ответом на сообщение (в чат) |
| `!кубик [дартс\|баскет\|футбол\|боулинг\|слот]` | настоящий анимированный кубик Telegram |
| `!монетка` · `!выбери а, б или в` | случайность с анимацией |
| `!напомни 10м текст` | напоминание в бота (`!напомни` — список, `!напомни удалить N`) |
| `!заметка текст` · `!заметки` | заметки, хранятся в SQLite (`!заметка удалить N`) |
| `!help` | список всех команд (в бота) |

Курс, погода и перевод берутся из бесплатных сервисов (ЦБ РФ, CoinGecko, Open-Meteo, MyMemory) без ключей. Если сервис недоступен, бот сообщит вам в личку.

> **Важно про редактирование.** Бот сначала пытается отредактировать ваше сообщение через `editMessageText` с `business_connection_id`, но Telegram обычно разрешает боту править только сообщения, отправленные самим ботом. Поэтому на практике сработает запасной путь: бот удаляет ваше сообщение с командой и отправляет новое от вашего имени, после чего анимирует его. Для этого нужны права «отвечать» и «удалять отправленные сообщения». Если удалить не удалось, анимация всё равно запустится в новом сообщении, а команда останется в чате.

## Как добавить свою команду
Создайте файл `handlers/commands/my_cmd.py` (внутри доступны `ctx.say(текст)`, `ctx.animate(кадры)`, `ctx.reply_owner(текст)`, `ctx.text_arg`):
```python
from handlers.commands import CommandContext, command

@command("привет", aliases=("hi",), description="пример")
async def hi(ctx: CommandContext):
    await ctx.animate(["Привет", "Привет!", "Привет 👋"])
```
Модуль подхватится автоматически, ничего регистрировать не нужно.

## Структура
```
bot.py            точка входа, логирование, автоочистка
config.py         настройки из .env
db.py             SQLite (пользователи, подключения, сообщения, настройки; всё по uid)
animations.py     кадры анимаций, редактирование/запасной путь, блокировка по чатам
handlers/
  business.py     business_connection / message / edited / deleted
  private.py      /start /settings /stats
  commands/       роутер «!» и модули команд
```

## Ограничения
- Бот видит только сообщения, пришедшие, пока он работает; удалённое до запуска в бэкапе не найдётся (бот сообщит количество таких сообщений).
- Если у файла протух `file_id`, бот пришлёт текст и пометку, что медиа переотправить нельзя.
- Логи: `data/logs/bot.log` (ротация) и консоль.
